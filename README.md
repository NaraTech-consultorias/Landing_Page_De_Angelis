# Landing Page — De Angelis Fisioterapia

Landing page institucional e de alta conversão para a clínica **De Angelis Fisioterapia**, desenvolvida com React, Tailwind CSS, Lucide Icons e Vite, seguindo rigorosamente a identidade visual e o Brand Book oficial da marca.

---

## 🎨 Identidade Visual e Diretrizes da Marca

- **Slogan Principal:** *"Cuidar do corpo. Equilibrar a vida. Transformar caminhos."*
- **Frase de Fechamento:** *"Todo processo de transformação começa com um cuidado."*
- **Símbolo Central:** Borboleta azul em alta definição (símbolo de transformação como processo em fases).
- **Tipografia:**
  - `Cormorant SC` — Títulos e cabeçalhos em versalete/maiúsculas espaçadas.
  - `Montserrat` — Corpo de texto, legendas e botões.
- **Paleta de Cores Oficial:**
  - `#F2EDE6` — Creme / Off-white (Base clara)
  - `#59B8E9` — Azul Claro / Céu
  - `#153D94` — Azul Royal (Ações e CTAs)
  - `#406489` — Azul Acinzentado
  - `#C7B49D` — Bege / Areia
  - `#CCB17C` — Dourado / Areia Escuro
  - `#121A37` — Azul Profundo / Dark Navy

---

## 🛠️ Stack Tecnológica

- **React 18**
- **Vite 6**
- **Tailwind CSS 3**
- **Lucide React** (ícones com `strokeWidth={1.5}`)
- **Mobile-First & 100% Responsivo**
- **SEO tags semânticas & OpenGraph**
- **Atributos `data-testid` em todos os elementos interativos**

---

## 📋 Estrutura da Página

1. **Hero Section:** Logotipo oficial com borboleta, slogan institucional, subtexto e CTA WhatsApp.
2. **Apresentação da Marca:** Cuidado individualizado, escuta, respeito ao tempo e ambiente reservado com hora marcada.
3. **Conceito da Borboleta:** Reflexão sobre transformação como processo gradual de recuperação e equilíbrio.
4. **9 Especialidades:** Grid interativo com Acupuntura, Auriculoterapia, Florais de Bach, Fisioterapia Pélvica, Fertilidade, RPG, Liberação Miofascial, Osteopatia e Pilates Clínico Integrado.
5. **Missão, Visão e Valores:** Textos literais do Brand Book e cards para os 8 Valores Fundamentais.
6. **Equipe:** Cards para Dra. Hilda, Dra. Thailane e Dr. Léo Wilson com indicação de CREFITO pendente.
7. **Por Que Escolher a De Angelis:** 4 diferenciais exclusivos da clínica.
8. **CTA Final & Contato:** Fechamento emocional, informações de atendimento e endereço.
9. **Footer:** Identidade visual, redes sociais e copyright.
10. **Botão Flutuante de WhatsApp:** Fixo no canto inferior direito, na paleta oficial da marca.

## 🚀 Como Rodar o Projeto

```bash
# 1. Instalar dependências
npm install

# 2. Executar servidor de desenvolvimento
npm run dev

# 3. Gerar build de produção
npm run build

# 4. Visualizar build localmente
npm run preview
```
